# Alpine Coffee — Landing Page

Dark-themed responsive coffee shop landing page made using HTML/CSS, built from scratch as a portfolio project.

## Features
- Custom navbar with logo, nav links, search bar, and cart icon
- Animated hero section with hover effects on product image and coffee beans
- Ground shadow effect using radial gradients
- Google Fonts for a premium, editorial feel
- Font Awesome icons
- Product info section.
- Hover-interactive CTA buttons.

## Tech Stack
- HTML5
- CSS3 (Flexbox, transforms, transitions, gradients)

## Status

-  Hero section with headline, CTA buttons, and product animation
-  Product shadow and hover interactions
